更新内容
- 正答率を「総合 / 初回 / 再回答」に分離して表示
- 初回誤答を再回答した問題の改善率を表示
- 履歴CSV保存をiPhone向けに修正（File生成失敗時はBlobへフォールバック）
- CSVに attempt_no / attempt_type（first・repeat）を追加
- CSV作成後は保存準備欄へ自動スクロール
- 通常学習・復習・履歴なし練習は5問出題に対応済み
- チェック済み問題からも5問 / 10問 / 全部を選択して練習可能
- 既存の問題・履歴・チェック・解説はそのまま引き継ぎ

改善率の定義
- 初回が誤答で、かつ再回答した問題を対象
- その問題の最新回答が正解なら「改善」として集計
